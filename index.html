Delivery timeline

A fixed seven-day build sequence

From a fresh server rack to production handoff in exactly one week, executed with automated shell scripts and GitOps pipelines.

Day 01 Hardware & OS

Server OS preparation

Ubuntu 24.04 LTS across all 19+ nodes. Static addressing, time sync and TLS certificate generation.

Linux · Bash · OpenSSL

Day 02 Networking & K8s

HA infrastructure & Kubernetes

HA DNS (Bind9 + Keepalived), HA load balancers (HAProxy + Keepalived) and HA Kubernetes control planes via kubeadm.

kubeadm · Bind9 · HAProxy

Day 03 GitOps platform

GitLab & GitOps setup

Dedicated GitLab CE server, repository import and ArgoCD controllers deployed across every cluster.

GitLab CE · ArgoCD · Docker

Day 04 Storage & mesh

Rook-Ceph & Istio Ambient

Distributed NVMe storage pools and sidecarless service mesh wired into the workload cluster.

Rook-Ceph · Istio Ambient

Day 05 CI/CD & registry

Harbor & Jenkins pipelines

Harbor OCI registry on the admin cluster, Jenkins CI/CD on the workload cluster with Cosign image signing.

Harbor · Jenkins · Cosign

Day 06 Telemetry

Observability stack

Prometheus, Thanos, Grafana Alloy, Loki and Tempo for centralised metrics, logs and traces.

Prometheus · Thanos · Loki · Tempo

Day 07 · Handoff

Demo application & HA failover drills

We deploy a Spring MVC reference application, run failover drills across DNS, load balancer and control plane VIPs, then hand over the GitOps repositories and operational runbooks.

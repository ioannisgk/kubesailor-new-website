Production Isolation Pattern

The 3-Cluster Bare Metal Blueprint

Hyperscaler cloud setups mix management planes with workload traffic. KubeSailor enforces strict physical and logical separation into three specialized clusters.

MANAGEMENT PLANE

Admin & Governance Control Cluster

Isolated, highly secure management plane running GitLab CE, ArgoCD GitOps engine, Harbor registry, and Prometheus/Thanos telemetry stack.

  • Ubuntu 24.04 LTS control plane nodes
  • Automated GitOps sync via ArgoCD
  • Centralized GitLab & Harbor credential management
RECOMMENDED HARDWARE SPECIFICATION:
Control Nodes: 3x Control Plane + Worker
CPU per Node: 8 vCPU / 16GB RAM
Disk: Standard SSD / NVMe
Network: Static IP Network Topology
WORKLOAD RUNTIME

Workload Compute Cluster (Istio Ambient Mesh)

High-throughput bare metal execution layer running Istio Ambient Mode for sidecarless L7 traffic routing, HAProxy + Keepalived load balancing, and Jenkins CI/CD pipeline integration.

  • Sidecarless L7 proxy routing with Istio Ambient
  • Containerized application workloads via kubeadm & ArgoCD
  • HAProxy + Keepalived VRRP Virtual IP load balancing
RECOMMENDED HARDWARE SPECIFICATION:
Compute Nodes: 4x Bare Metal Servers (1 CP + 3 Worker)
CPU per Node: 8 vCPU / 16GB RAM minimum
Disk: Standard SSD / NVMe OS Drive
Network: Static IP Network Interface
PERSISTENT STORAGE

Rook-Ceph Distributed Storage Cluster

Enterprise distributed storage pool using Rook-Ceph over raw NVMe drives. Provides high-availability Block Storage (RWO/RWX), Shared Filesystem (CephFS), and S3-compatible Object Storage.

  • Sub-millisecond NVMe OSD disk throughput
  • Automatic 3x replication & failover recovery
  • Built-in S3 Object Storage API endpoint
RECOMMENDED HARDWARE SPECIFICATION:
Storage Nodes: 3x Dedicated Storage Servers
OSDs per Node: 4x to 8x Datacenter NVMe SSDs
RAM: 64GB+ RAM (Ceph Caching)
Network: Dedicated Storage Network Topology
